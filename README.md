## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/krishrajputw/my-portfolio.git
```

Navigate to the project:

```bash
cd my-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## 📧 Backend

The project includes a Node.js and Express backend for handling contact-form submissions.

Environment variables are required:

```text
EMAIL_USER=your-email
EMAIL_APP_PASSWORD=your-app-password
```

Keep `.env` files private and never commit credentials to GitHub.
